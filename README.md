# Adventurer's Rise

**Adventurer's Rise** is a Roblox lite-MMORPG progression game built around simulator simplicity, interconnected skill progression, visible character growth, shared-world bosses, and player-owned training plots.

## Current Direction

- One persistent character with no permanent class lock
- Combat paths: Melee, Defense, Ranged, and Magic
- Gathering and production skills: Mining, Woodcutting, Smithing, Fletching, and Arcana
- Six permanent Ascension ranks from Adventurer through Ascendant
- Grounded medieval-adventure setting that progresses into high fantasy
- Shared player plots with upgradeable combat training stations and later personal production stations
- Shared server bosses with personal RNG loot rolls
- Soft-gated progression regions with increasingly dangerous enemies and resources
- One primary soft currency: Gold Coins
- Lightweight mastery trees for every skill

## Project Status

Pre-production and core design. Implementation has not begun.

The current goal is to define the smallest launch scope that can support strong first-session retention, meaningful long-term progression, and repeat play while remaining practical to build primarily through an AI-orchestrated Roblox Studio workflow.
